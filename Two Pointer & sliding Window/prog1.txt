while(r<A.length()){        --O(N)
    sum=sum+A[r];

    while(sum>k){           --O(N)
        sum=sum-A[l];
        l++;
    }

    if(sum<=k){

// Max Subarray with sum<=k
//Brute Approach
A          2   5   1   10   10
index      0   1   2   3    4
                                i
                            j



k=14
sum=0+5=5
maxLen=3


//Psedocode

int maxlen=0;
for(int i=0;i<A.length();i++){          
    sum=0;
    for(int j=i;j<A.length();j++){      
        sum=sum+A[j];
        if(sum>k){
            break;
        }
        else{
            maxlen=Max(maxlen,j-i+1);
        }
    }
}

return maxLen;

Here the Outer loop runs for N times 
the inner loop runs upto N times for each i
Time complexity becomes O(N*2)
Space complexity becomes O(1) since other then maxLen,i,j,sum we are not consuming any Space
